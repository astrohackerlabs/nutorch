Let's get started! :elephant:

The next sections will give you a [short tour of Nushell by example](/docs/shell/book/quick_tour/) (including how to get help from within Nushell) and show you how to [move around your file system](/docs/shell/book/moving_around/).

Then, because Nushell takes some design decisions that are quite different from typical shells or dynamic scripting languages, make sure to check out [Thinking in Nu](/docs/shell/book/thinking_in_nu/) where we explain some of these concepts.
